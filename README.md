### 👋 Về mình

[#-ve-minh](#-ve-minh)

Mình là **sinh viên ngành Kỹ thuật phần mềm**, hiện đang làm việc với các dự án full-stack web và hệ thống thương mại điện tử **Magento 2**.

- 🔭 **Đang làm**: Các dự án web full-stack và hệ thống e-commerce trên nền tảng Magento 2.
- 👯 **Mong muốn hợp tác**: Các dự án phần mềm sử dụng Java, React, PHP và Node.js.
- 🤝 **Cần hỗ trợ về**: Kiến thức chuyên sâu về AWS cloud và Docker.
- 🌱 **Đang học**: Tiếng Nhật (trình độ N5) và quản trị hệ thống Linux/Ubuntu.
- 💬 **Hỏi mình về**: Thiết kế cơ sở dữ liệu, phát triển web, chiến thuật cờ vua và kỹ thuật đua xe F1.
- ⚡ **Fun fact**: Lúc rảnh mình thích đọc sách, xem phim hoặc theo dõi các giải đua xe.
